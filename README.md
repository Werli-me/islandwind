## 🎉 Первый публичный релиз IslandWind v1.0.0 (Windows 10 / 11)

Легковесный и кастомизируемый виджет **Dynamic Island** для рабочего стола Windows, написанный на чистом C++ (Win32 API + Direct2D) без лишней нагрузки на систему.

### ✨ Что внутри версии v1.0.0:
* 🎵 **Умный медиаплеер и караоке:** поддержка любых браузеров и плееров через системный SMTC, обложки треков, автоматический поиск синхронизированного текста песен (LRC) с неоновым свечением активного слова и **адаптивным цветом под обложку**.
* 🔊 **Круги под биты музыки:** 3 режима аудио-реактивных волн (Импульс, Неоновый ореол, Каскад) + живой 4-полосный эквалайзер.
* 🎮 **Игровой режим (Game Mode HUD по `Alt + G`):** компактная игровая панель с мониторингом **FPS**, времени кадра (**Frametime мс**), нагрузки **CPU**, **GPU**, видеопамяти **VRAM**, **RAM** и сетевого **пинга (ICMP)** + функция быстрой очистки ОЗУ и режим прозрачности для кликов мыши (*Click-Through*).
* 📱 **Интеграция со смартфоном:** перехват входящих звонков и уведомлений из приложения «Связь с телефоном» (Phone Link) со всплывающим баннером и историей во вкладке «Связь».
* 🌤 **Погода в реальном времени:** почасовой и недельный прогноз с векторными иконками (Open-Meteo + резервный wttr.in).
* 🗂 **Полка файлов, Буфер обмена, Календарь и Заметки:** перетаскивание файлов (Drag & Drop), автосохранение истории скопированного текста и быстрый блокнот прямо в островке.
* 🐾 **Питомец на острове:** интерактивный Котик или Геккончик, который гуляет по капсуле и танцует под музыку.
* 🎨 **Встроенный конфигуратор:** переключение между **прилипающим к верху вырезом** («чёлкой») и **парящим островом**, настройка цветов, размеров, задержки раскрытия и порядка вкладок.

---

### 🚀 Как запустить:
1. Скачайте файл **`DynamicIsland.exe`** ниже в разделе **Assets**.
2. Запустите его — программа не требует установки и сама создаст файл конфигурации рядом с собой.
3. Нажмите **правой кнопкой мыши по островку** (или дважды кликните по иконке в системном трее), чтобы открыть окно настроек.

> 💡 *Примечание:* При первом запуске фильтр Windows SmartScreen может показать окно предупреждения (так как у файла нет платной цифровой подписи). Нажмите **«Подробнее» → «Выполнить в любом случае»**.
